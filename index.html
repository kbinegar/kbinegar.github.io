Blog

Reflections on technical writing in the age of AI, docs-as-code, and the challenges of learning new technologies.

July 2026

DRAFT

As we continue to watch Language Learning Models (LLMs), or AI “agents,” absorb larger and larger quantities of labor expectations, many pre-established technical writing professionals have begun considering the security of writing roles. I saw this myself at the 2026 Write the Docs (WTD) Conference in Portland, OR. Hosted in May, several, if not the majority of, discussions were regarding AI—with some notable figures asking the question: “When is it time to stop writing for humans, and begin writing solely for agents?”

05 / How I Built This

How I Built This Site

This portfolio's initial HTML/CSS scaffold was generated through iterative prompts with Claude. Having previously taught myself HTML and CSS, I used that generated foundation to understand the structure and customize the site independently. All written content, documentation samples, information architecture, and portfolio strategy are my own work. Throughout development, I independently debugged implementation issues using browser developer tools and standard web troubleshooting practices.

Stack

Plain HTML and CSS, no framework or build step. Hosted free on GitHub Pages, deployed straight from the repository's main branch.

Structure

One index.html with the five main sections as anchors, plus standalone pages under /samples and /blog so each writing piece has its own shareable link.

What I am changing and developing in the future

I plan to transfer this portfolio to Docusaurus to demonstrate experience with SSGs.

I will also be integrating automations and plan to demonstrate that pipeline in a new section.
